# Growx Location — Implementation Bootstrap

**File:** `11-implementation-bootstrap.md`

## Goal

Turn the architecture into a working repository.

After this file is complete, the repo must:

- use Turborepo,
- use Bun,
- contain the Cloudflare Worker API app,
- contain shared packages,
- run locally,
- pass typecheck,
- pass lint,
- return a working `/health` response.

Do not connect Supabase in this file yet.

---

# 1. Repository Root

Existing folder:

```text
growx-loc
```

Open terminal inside it.

Initialize Git:

```bash
git init
```

Initialize Bun:

```bash
bun init -y
```

Install root tooling:

```bash
bun add -D turbo typescript @biomejs/biome
```

# 3. Root package.json

Replace the root `package.json` with:

```json
{
  "name": "growx-loc",
  "private": true,
  "workspaces": [
    "apps/*",
    "packages/*"
  ],
  "scripts": {
    "dev": "turbo dev",
    "build": "turbo build",
    "typecheck": "turbo typecheck",
    "lint": "turbo lint",
    "format": "biome format --write .",
    "check": "biome check ."
  },
  "devDependencies": {
    "@biomejs/biome": "latest",
    "turbo": "latest",
    "typescript": "latest"
  }
}
```

Check Bun version:

```bash
bun --version
```

Then add:

```json
"packageManager": "bun@YOUR_VERSION"
```

Example:

```json
"packageManager": "bun@1.3.2"
```

Use your actual installed version.

# 15. API Entry Point

Create:

`apps/api/src/index.ts`

```ts
import { Hono } from "hono";
import { health } from "./routes/health";
import type { Bindings } from "./types/bindings";

type Env = {
  Bindings: Bindings;
};

const app = new Hono<Env>();

app.get("/", (c) => {
  return c.json({
    name: "Growx Location API",
    status: "operational",
    version: "v1",
  });
});

app.route("/health", health);

export default app;
```
